# Answer

This section provides a detailed explanation for Question 7 related to Wi‑Fi PHY layer concepts.

## Overview
The IEEE 802.11 PHY layer is responsible for modulation, coding, synchronization, signal transmission, and radio frequency operations in WLAN communication systems.

## Key Concepts
- Signal encoding
- Modulation techniques
- Channel allocation
- OFDM/OFDMA
- MIMO technologies
- PPDU structures
- Data rate calculations

## Technical Explanation
Modern Wi‑Fi standards improve throughput and reliability using advanced PHY layer techniques such as:
- Orthogonal Frequency Division Multiplexing (OFDM)
- Orthogonal Frequency Division Multiple Access (OFDMA)
- Multiple Input Multiple Output (MIMO)
- Beamforming
- Channel bonding
- Higher order modulation schemes

## Importance in WLAN
These technologies improve:
- Spectral efficiency
- Throughput
- Latency
- Multi‑user performance
- Reliability in dense deployments

## Conclusion
Understanding PHY layer operation is critical for designing, debugging, optimizing, and securing enterprise WLAN systems.
