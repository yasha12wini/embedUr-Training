# Question 2
## What are DSSS and FHSS? How do they work?

# Answer

DSSS (Direct Sequence Spread Spectrum) and FHSS (Frequency Hopping Spread Spectrum) are spread spectrum techniques used in early IEEE 802.11 PHY layer implementations.

---

# What is Spread Spectrum?

Spread spectrum techniques spread a signal across a wider bandwidth than required for transmitting data. This improves:
- Resistance to interference
- Security
- Reliability
- Noise immunity

---

# DSSS (Direct Sequence Spread Spectrum)

## Working Principle

In DSSS, the original data signal is multiplied by a high‑rate pseudo‑random code called a chipping sequence.

This spreads the signal over a larger frequency range.

---

## DSSS Transmission Process

1. Original data bits are generated.
2. Each bit is multiplied with a chipping code.
3. The transmitted signal occupies a wider bandwidth.
4. Receiver uses the same code to recover the original data.

---

## Example

If:
- Data bit = 1
- Chipping code = 10110110

The transmitted sequence becomes the expanded coded signal.

---

# Advantages of DSSS

- Good resistance to narrowband interference
- Better signal recovery
- Improved noise immunity
- More secure than narrowband transmission

---

# Disadvantages of DSSS

- Lower spectral efficiency
- Higher bandwidth requirement
- More complex synchronization

---

# FHSS (Frequency Hopping Spread Spectrum)

## Working Principle

In FHSS, the transmitter rapidly changes carrier frequencies according to a pseudo‑random hopping pattern shared with the receiver.

---

## FHSS Transmission Process

1. Data is divided into short bursts.
2. Each burst is transmitted on a different frequency.
3. Transmitter and receiver synchronize hopping patterns.
4. Receiver follows the same hopping sequence to reconstruct data.

---

# Types of FHSS

| Type | Description |
|---|---|
| Slow FHSS | Hop rate slower than symbol rate |
| Fast FHSS | Hop rate faster than symbol rate |

---

# Advantages of FHSS

- Strong resistance to jamming
- Better coexistence with other devices
- Reduced interference effects

---

# Disadvantages of FHSS

- Lower throughput
- Synchronization complexity
- Limited spectral efficiency

---

# DSSS vs FHSS

| Feature | DSSS | FHSS |
|---|---|---|
| Technique | Spreads using chipping codes | Changes carrier frequency |
| Bandwidth Usage | Wide continuous spectrum | Narrow hopping channels |
| Interference Resistance | Good | Excellent |
| Throughput | Higher | Lower |
| Complexity | Moderate | Higher synchronization complexity |
| Used In | 802.11b | Early 802.11 |

---

# Conclusion

DSSS and FHSS were foundational PHY technologies in early Wi‑Fi systems. Although modern WLANs primarily use OFDM and OFDMA, DSSS and FHSS introduced the essential concepts of robust wireless communication and interference mitigation.
