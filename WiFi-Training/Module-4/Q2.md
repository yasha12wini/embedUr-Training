# IEEE 802.11 MAC Header Frame Format and Field Explanation

## Introduction

The IEEE 802.11 MAC header is used in wireless frames to carry control information required for communication between stations and access points.

Compared to Ethernet:
- Wi-Fi headers are more complex
- Wireless communication requires additional control information

The MAC header supports:
- Addressing
- Sequencing
- QoS
- Security
- Fragmentation
- Power management

---

# General 802.11 MAC Frame Structure

An 802.11 frame contains:
1. MAC Header
2. Frame Body
3. FCS (Frame Check Sequence)

---

# MAC Header Format

| Field | Size |
|---|---|
| Frame Control | 2 Bytes |
| Duration/ID | 2 Bytes |
| Address 1 | 6 Bytes |
| Address 2 | 6 Bytes |
| Address 3 | 6 Bytes |
| Sequence Control | 2 Bytes |
| Address 4 (optional) | 6 Bytes |
| QoS Control (optional) | 2 Bytes |
| HT Control (optional) | 4 Bytes |

---

# 1. Frame Control Field

This field defines:
- Frame type
- Subtype
- Protocol behavior

---

## Important Subfields

### Protocol Version
Indicates 802.11 protocol version.

### Type
Defines frame category:
- Management
- Control
- Data

### Subtype
Specifies exact frame type.

Examples:
- Beacon
- ACK
- RTS
- CTS

### To DS / From DS
Indicates frame direction relative to distribution system.

### Retry Bit
Indicates retransmission.

### Power Management Bit
Indicates power-saving state.

### Protected Frame Bit
Indicates encrypted frame.

---

# 2. Duration/ID Field

Used for:
- NAV calculation
- Channel reservation timing

Helps other stations know:
- How long medium will remain busy

---

# 3. Address Fields

802.11 may use up to four MAC addresses.

---

## Address 1
Usually receiver address.

## Address 2
Usually transmitter address.

## Address 3
BSSID or destination/source depending on frame direction.

## Address 4
Used mainly in wireless bridging/WDS scenarios.

---

# Why Four Addresses?

Wireless distribution systems require additional addressing flexibility.

This is more complex than Ethernet.

---

# 4. Sequence Control Field

Contains:
- Sequence number
- Fragment number

Purpose:
- Detect duplicates
- Reassemble fragments
- Manage retransmissions

---

# 5. QoS Control Field

Used in QoS-enabled frames.

Contains:
- Traffic priority
- Queue information

Supports:
- Voice
- Video
- Best effort traffic

---

# 6. HT Control Field

Used in advanced PHY operations.

Related to:
- High throughput features
- Beamforming
- Control signaling

---

# 7. Frame Body

Contains:
- Payload
- Management information
- Control information

Varies based on frame type.

---

# 8. FCS (Frame Check Sequence)

Used for:
- Error detection

Typically uses CRC.

---

# Frame Categories

## Management Frames
- Beacon
- Probe
- Authentication
- Association

## Control Frames
- ACK
- RTS
- CTS
- Block ACK

## Data Frames
Carry actual payload traffic.

---

# Real-World Importance

Understanding MAC headers is important for:
- Packet analysis
- Wireshark debugging
- Driver development
- WLAN troubleshooting

---

# Key Takeaways

- 802.11 MAC headers are more complex than Ethernet headers.
- Multiple address fields support wireless distribution systems.
- Frame control fields determine frame behavior.
- MAC headers are essential for reliable WLAN communication.
