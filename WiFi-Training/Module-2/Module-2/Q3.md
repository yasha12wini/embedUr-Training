# Question 3
## Where does CAPWAP fit in the OSI model? What are the two tunnels in CAPWAP and their purpose?

# Answer

CAPWAP primarily operates at the Application Layer of the OSI model while using UDP transport at the Transport Layer.

---

# CAPWAP in OSI Model

| OSI Layer | CAPWAP Role |
|---|---|
| Application Layer | CAPWAP protocol operation |
| Transport Layer | UDP communication |
| Network Layer | IP routing |
| Data Link Layer | Ethernet/Wi‑Fi transmission |

---

# CAPWAP Tunnels

CAPWAP creates two logical tunnels between AP and WLC:

1. Control Tunnel
2. Data Tunnel

---

# 1. Control Tunnel

## Purpose
Used for management and control communication.

## Functions
- AP registration
- Configuration download
- Keepalive messages
- Firmware management
- RF management
- Security management

## Port
UDP 5246

---

# 2. Data Tunnel

## Purpose
Used for transporting client traffic.

## Functions
- Encapsulation of wireless frames
- Forwarding client packets to WLC
- Centralized switching

## Port
UDP 5247

---

# Tunnel Architecture

```text
+----------------------+
| Control Tunnel       |
| UDP 5246             |
| Management Traffic   |
+----------------------+

+----------------------+
| Data Tunnel          |
| UDP 5247             |
| Client Data Traffic  |
+----------------------+
```

---

# DTLS Security

CAPWAP commonly uses DTLS:
- Encrypts control traffic
- Provides authentication
- Protects AP‑controller communication

---

# Conclusion

CAPWAP operates using separate control and data tunnels to efficiently manage wireless APs while securely transporting client traffic in enterprise WLAN environments.
