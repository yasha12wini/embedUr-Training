# Question 1
## Brief about SplitMAC architecture and how it improves the AP's performance

# Answer

SplitMAC architecture is a wireless LAN architecture where MAC layer responsibilities are divided between the Access Point (AP) and the Wireless LAN Controller (WLC). This architecture is commonly used in enterprise WLAN deployments with lightweight APs.

---

# Traditional MAC vs SplitMAC

In traditional autonomous APs:
- Entire MAC functionality is processed locally inside the AP.

In SplitMAC:
- Time‑critical MAC operations remain on the AP.
- Non‑real‑time MAC functions are handled by the WLC.

---

# MAC Layer Division

## Functions Performed by AP
These are latency‑sensitive operations:
- Beacon transmission
- Probe response handling
- Frame acknowledgments
- RTS/CTS handling
- Encryption/decryption
- Real‑time packet transmission

## Functions Performed by WLC
These are centralized control operations:
- Authentication
- Association management
- RF management
- QoS policies
- Security policies
- Roaming decisions
- VLAN assignment

# Advantages of SplitMAC

## 1. Centralized Management
All APs are managed from a single controller.

## 2. Easier Configuration
Administrators configure WLAN policies centrally.

## 3. Improved Roaming
Controller coordinates seamless roaming between APs.

## 4. Better Security
Centralized authentication and policy enforcement.

## 5. RF Optimization
WLC dynamically adjusts:
- Channel selection
- Transmit power
- Interference mitigation

## 6. Reduced AP Complexity
Lightweight APs require less processing power.

| Faster Roaming | Better mobility handling |
| Dynamic RF Management | Improved signal quality |

---

# Conclusion

SplitMAC architecture improves enterprise WLAN scalability, manageability, and performance by separating real‑time wireless functions from centralized network management functions.
