# Question 1
## In which OSI layer does the Wi‑Fi standard/protocol fit?

# Answer

Wi‑Fi primarily operates in the Physical Layer (Layer 1) and Data Link Layer (Layer 2) of the OSI model.

---

# Wi‑Fi in the OSI Model

| OSI Layer | Wi‑Fi Role |
|---|---|
| Layer 1 — Physical Layer | RF transmission, modulation, channels, frequencies |
| Layer 2 — Data Link Layer | MAC addressing, frame transmission, access control |

---

# Layer 1 — Physical Layer Responsibilities

The PHY layer handles:
- Radio signal transmission
- Frequency band operation
- Modulation techniques
- Channel selection
- Signal encoding
- Data rate handling

Examples:
- OFDM
- DSSS
- MIMO
- OFDMA

---

# Layer 2 — Data Link Layer Responsibilities

The MAC sublayer handles:
- Frame formatting
- MAC addressing
- CSMA/CA
- Error detection
- Association/authentication
- Retransmissions

---

# Example

When a laptop connects to Wi‑Fi:
1. PHY layer transmits radio signals.
2. MAC layer manages wireless access.
3. IP traffic is forwarded to higher OSI layers.

---

# Conclusion

Wi‑Fi standards mainly operate in OSI Layer 1 and Layer 2, enabling wireless signal transmission and wireless medium access control.
