# Question 10
## List down the Wi‑Fi topologies and use cases of each one.

# Answer

Wi‑Fi topologies define how wireless devices and access points are organized within a network.

---

# Types of Wi‑Fi Topologies

1. Infrastructure Mode
2. Ad‑Hoc Mode
3. Mesh Topology
4. Point‑to‑Point
5. Point‑to‑Multipoint

---

# 1. Infrastructure Mode

Devices communicate through an Access Point.

---

## Use Cases
- Home Wi‑Fi
- Office WLANs
- Enterprise networks

---

# 2. Ad‑Hoc Mode

Devices communicate directly without an AP.

---

## Use Cases
- Temporary file sharing
- Device‑to‑device communication
- Small isolated networks

---

# 3. Mesh Topology

Multiple APs form interconnected wireless paths.

---

## Use Cases
- Smart cities
- Large campuses
- Industrial IoT

---

# 4. Point‑to‑Point Topology

Wireless bridge between two locations.

---

## Use Cases
- Building‑to‑building connectivity
- Remote site links

---

# 5. Point‑to‑Multipoint Topology

One central AP connects multiple remote devices.

---

## Use Cases
- Rural internet distribution
- Campus wireless distribution

---

# Topology Comparison

| Topology | Main Feature | Typical Usage |
|---|---|---|
| Infrastructure | AP‑based | Enterprise WLAN |
| Ad‑Hoc | Peer‑to‑peer | Temporary networks |
| Mesh | Self‑healing network | Large coverage |
| Point‑to‑Point | Dedicated link | Building connectivity |
| Point‑to‑Multipoint | Centralized distribution | ISP distribution |

---

# Conclusion

Different Wi‑Fi topologies are designed for different deployment scenarios depending on coverage, scalability, redundancy, and connectivity requirements.
