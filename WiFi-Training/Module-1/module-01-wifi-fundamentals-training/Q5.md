# Question 5
## Difference between Bridge mode and Repeater mode

# Answer

Bridge mode and Repeater mode are wireless operating modes used to extend or connect networks.

---

# Bridge Mode

Bridge mode connects two separate wired networks wirelessly.

Purpose:
- Network interconnection

---

# Bridge Mode Characteristics

- Connects LAN segments
- Transparent forwarding
- Usually point‑to‑point
- No client servicing in some configurations

---

# Repeater Mode

Repeater mode extends wireless coverage by retransmitting signals.

Purpose:
- Range extension

---

# Repeater Mode Characteristics

- Receives and retransmits signals
- Expands coverage area
- Supports wireless clients

---

# Comparison

| Feature | Bridge Mode | Repeater Mode |
|---|---|---|
| Main Purpose | Connect networks | Extend coverage |
| Client Support | Limited | Yes |
| Throughput Impact | Minimal | Reduced throughput |
| Typical Usage | Building‑to‑building links | Dead zone coverage |

---

# Conclusion

Bridge mode is mainly used for network interconnection, while repeater mode is used for extending wireless coverage areas.
