# Question 9
## List down the types of Wi‑Fi internet connectivity backhaul. Share your home/college wireless internet connectivity backhaul name and its properties.

# Answer

Backhaul refers to the connection between the WLAN infrastructure and the internet service provider or core network.

---

# Types of Wi‑Fi Backhaul Connectivity

| Backhaul Type | Description |
|---|---|
| Fiber Optic | High‑speed optical internet |
| Ethernet | Wired LAN backhaul |
| DSL | Telephone line broadband |
| Cable Internet | Coaxial cable broadband |
| Microwave Link | Wireless point‑to‑point |
| Cellular Backhaul | 4G/5G internet |
| Satellite | Long‑distance internet access |

---

# Common Home/College Backhaul

Most modern homes and colleges use:
- Fiber broadband
- Ethernet distribution

---

# Example Properties of Fiber Backhaul

| Property | Value |
|---|---|
| Medium | Optical Fiber |
| Speed | 100 Mbps to multi‑Gbps |
| Latency | Very low |
| Reliability | High |
| Interference | Minimal |

---

# Enterprise/College Backhaul

Large campuses may use:
- Redundant fiber links
- MPLS networks
- High‑capacity Ethernet aggregation

---

# Conclusion

Backhaul connectivity determines overall internet performance, reliability, and scalability of WLAN infrastructure.
