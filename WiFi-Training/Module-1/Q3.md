# Question 3
## What are BSS and ESS?

# Answer

BSS and ESS are WLAN architecture concepts defined in IEEE 802.11.

---

# BSS (Basic Service Set)

A BSS is the fundamental building block of a wireless LAN.

It consists of:
- One Access Point (AP)
- Connected wireless clients

All devices communicate through the AP.

---

# Components of BSS

| Component | Description |
|---|---|
| Access Point | Central wireless device |
| Stations (STA) | Wireless clients |
| BSSID | MAC address identifying the BSS |

---

# BSS Example

```text
Laptop ----|
Phone  ----|--> Access Point
Tablet ----|
```

---

# ESS (Extended Service Set)

An ESS is formed when multiple BSSs are connected together using a distribution system.

Typically:
- Multiple APs
- Same SSID
- Seamless roaming

---

# ESS Characteristics

- Larger wireless coverage
- Client roaming support
- Centralized WLAN connectivity

---

# ESS Example

```text
AP1 ----- Switch ----- AP2 ----- AP3
 |                       |         |
Clients               Clients   Clients
```

---

# Difference Between BSS and ESS

| Feature | BSS | ESS |
|---|---|---|
| Number of APs | One | Multiple |
| Coverage Area | Small | Large |
| Roaming | No | Yes |
| Scalability | Limited | High |

---

# Conclusion

BSS provides a single wireless coverage area, while ESS combines multiple BSSs to create larger enterprise WLAN deployments with roaming capability.
