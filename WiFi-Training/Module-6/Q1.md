# Pillars of Wi-Fi Security

## Introduction

Wi-Fi security is designed to protect wireless communication from unauthorized access, data theft, impersonation, and network attacks. Unlike wired networks, wireless communication occurs over radio frequency (RF) signals, making transmissions accessible to anyone within signal range. Because of this, strong security mechanisms are critical in WLAN deployments.

The foundation of Wi-Fi security is generally built on four major pillars:

1. Authentication
2. Encryption
3. Integrity Protection
4. Access Control

---

## 1. Authentication

### Definition

Authentication is the process of verifying the identity of a device or user before granting access to the wireless network.

### Purpose

Authentication ensures that:
- Only authorized users can join the network
- Rogue or unauthorized devices are blocked
- Network resources are protected

### Types of Authentication in Wi-Fi

#### Open Authentication
- No identity verification
- Used in open/public Wi-Fi networks
- No password required

#### Pre-Shared Key (PSK) Authentication
- Uses a shared password/passphrase
- Common in home and small office networks
- Example: WPA2-Personal

#### Enterprise Authentication (802.1X)
- Uses centralized authentication servers such as RADIUS
- Each user gets unique credentials
- Common in enterprises and organizations

### Example

When a laptop connects to a WPA2-Personal network:
1. User enters Wi-Fi password
2. Client derives cryptographic keys
3. AP verifies whether both sides possess the same secret

---

## 2. Encryption

### Definition

Encryption converts readable data (plaintext) into unreadable data (ciphertext) using cryptographic algorithms.

### Purpose

Encryption ensures:
- Confidentiality of transmitted data
- Protection against packet sniffing
- Secure wireless communication

### Common Encryption Algorithms

| Standard | Encryption |
|---|---|
| WEP | RC4 |
| WPA | TKIP |
| WPA2 | AES-CCMP |
| WPA3 | AES-GCMP / SAE |

### Example

If a user accesses banking websites over Wi-Fi:
- Encryption prevents attackers from reading packets captured over the air

---

## 3. Integrity Protection

### Definition

Integrity protection ensures that transmitted packets are not altered during transmission.

### Purpose

It protects against:
- Packet tampering
- Replay attacks
- Frame modification attacks

### Mechanisms Used

- MIC (Message Integrity Check)
- CCMP integrity validation
- Replay counters
- Nonce-based protection

### Importance

Without integrity checks:
- Attackers could modify packets in transit
- Malicious payload injection becomes possible

---

## 4. Access Control

### Definition

Access control determines what authenticated users are allowed to access.

### Examples

- VLAN assignment
- MAC filtering
- Role-based policies
- Guest isolation
- Captive portals

### Enterprise Usage

In enterprise Wi-Fi:
- Employees may access internal servers
- Guests may only access the internet

This separation improves network security.

---

## Additional Security Components

### Key Management
Secure generation and exchange of encryption keys.

### Mutual Authentication
Both AP and client verify each other’s identity.

### Rogue AP Detection
Helps identify unauthorized access points.

### Protected Management Frames (PMF)
Introduced in WPA3 to protect management traffic.

---

## Real-World Importance

Wi-Fi security is essential because wireless networks are vulnerable to:
- Eavesdropping
- Man-in-the-middle attacks
- Unauthorized access
- Session hijacking
- Packet injection

Modern enterprise networks rely heavily on strong Wi-Fi security architecture.

---

## Key Takeaways

- Authentication verifies identity.
- Encryption protects confidentiality.
- Integrity mechanisms prevent tampering.
- Access control limits resource usage.
- Modern Wi-Fi security combines all these pillars together.
