# Question 4
## What is the significance of OFDM in WLAN? How does it improve performance?

# Answer

OFDM (Orthogonal Frequency Division Multiplexing) is one of the most important technologies used in modern Wi‑Fi PHY layers. It significantly improves throughput, spectral efficiency, and robustness against interference and multipath fading.

---

# Basic Principle of OFDM

Instead of transmitting data using a single carrier, OFDM divides the channel into many orthogonal subcarriers.

Each subcarrier carries a portion of the data stream simultaneously.

---

# OFDM Operation

1. High‑speed data is divided into parallel low‑rate streams.
2. Streams are mapped onto multiple subcarriers.
3. IFFT converts frequency‑domain signals to time‑domain.
4. Cyclic prefix is added.
5. Signal is transmitted.

At the receiver:
- FFT recovers subcarriers.
- Symbols are demodulated.
- Original data is reconstructed.

---

# Why OFDM is Important

## 1. Multipath Resistance
Wireless signals reflect from walls and objects.

OFDM handles delay spread effectively using:
- Narrowband subcarriers
- Guard intervals
- Cyclic prefix

---

## 2. High Spectral Efficiency
Subcarriers overlap spectrally while remaining orthogonal.

This allows:
- Better bandwidth utilization
- Higher throughput

---

## 3. Reduced ISI
ISI (Inter Symbol Interference) is minimized due to long symbol duration and cyclic prefix.

---

## 4. Adaptive Modulation
Different modulation schemes can be used dynamically:
- BPSK
- QPSK
- 16‑QAM
- 64‑QAM
- 1024‑QAM

---

# OFDM in Wi‑Fi Standards

| Standard | OFDM Usage |
|---|---|
| 802.11a | First major OFDM implementation |
| 802.11g | OFDM at 2.4 GHz |
| 802.11n | OFDM + MIMO |
| 802.11ac | Advanced OFDM |
| 802.11ax | OFDMA extension |

---

# Advantages of OFDM

| Advantage | Benefit |
|---|---|
| High Throughput | Parallel transmission |
| Better Reliability | Resistant to fading |
| Efficient Spectrum Usage | Overlapping subcarriers |
| Lower Equalization Complexity | Simplified receiver design |
| Scalability | Supports different bandwidths |

---

# Conclusion

OFDM revolutionized WLAN communication by enabling high‑speed, reliable wireless transmission. It forms the foundation for all modern Wi‑Fi generations and enables technologies such as MIMO and OFDMA.
