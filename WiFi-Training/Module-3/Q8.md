
# Difference Between OFDM and OFDMA

## Introduction

OFDM and OFDMA are advanced multi‑carrier transmission techniques widely used in modern wireless communication systems.

- OFDM = Orthogonal Frequency Division Multiplexing
- OFDMA = Orthogonal Frequency Division Multiple Access

OFDMA evolved from OFDM to support efficient multi‑user communication.

---

## OFDM Fundamentals

OFDM divides a channel into multiple orthogonal subcarriers.

Characteristics:
- All subcarriers assigned to one user at a time
- Parallel data transmission
- High spectral efficiency
- Strong multipath resistance

Used in:
- 802.11a/g/n/ac
- LTE downlink
- Digital broadcasting

---

## OFDMA Fundamentals

OFDMA extends OFDM by allowing:
- Multiple users to share subsets of subcarriers simultaneously

Each user gets:
- Resource Units (RUs)
- Allocated subcarrier groups

Used in:
- Wi‑Fi 6
- Wi‑Fi 7
- 5G NR

---

## Key Difference

### OFDM
Entire channel allocated to:
- One user per transmission interval

### OFDMA
Channel divided among:
- Multiple users simultaneously

---

## Resource Allocation

OFDM:
- Full bandwidth used by one device

OFDMA:
- Frequency resources split into RUs
- Different users assigned different RUs

---

## Efficiency Comparison

OFDMA significantly improves:
- Spectrum utilization
- Latency
- Network efficiency
- Small packet performance

Particularly useful in:
- Dense environments
- IoT networks
- Enterprise WLANs

---

## OFDMA Resource Units

Wi‑Fi 6 supports:
- 26‑tone RU
- 52‑tone RU
- 106‑tone RU
- 242‑tone RU
- 484‑tone RU
- 996‑tone RU

AP schedules users dynamically.

---

## Latency Performance

OFDM:
- Users wait for channel access
- Increased contention

OFDMA:
- Simultaneous transmissions
- Reduced contention overhead

Result:
- Lower latency
- Better QoS

---

## Uplink and Downlink

OFDMA supports:
- Uplink scheduling
- Downlink scheduling

AP centrally coordinates transmissions.

---

## Comparison Table

| Feature | OFDM | OFDMA |
|---|---|---|
| User Allocation | Single user | Multiple users |
| Spectrum Usage | Less efficient | Highly efficient |
| Latency | Higher | Lower |
| Contention | High | Reduced |
| Best Use Case | High throughput single user | Dense multi‑user networks |
| Introduced in Wi‑Fi | 802.11a | 802.11ax |

---

## Real‑World Impact

OFDMA improves:
- Stadium deployments
- Enterprise WLANs
- Smart homes
- IoT scalability

Benefits:
- Better airtime fairness
- Reduced collisions
- Improved battery efficiency

---

## Conclusion

OFDM revolutionized wireless communication by enabling efficient multi‑carrier transmission. OFDMA further enhanced WLAN performance by allowing simultaneous multi‑user access using Resource Units. Modern high‑density Wi‑Fi deployments depend heavily on OFDMA for improved scalability, reduced latency, and efficient spectrum utilization.
