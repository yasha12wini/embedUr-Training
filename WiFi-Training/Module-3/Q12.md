
# Wi‑Fi Data Rate Calculation

## Introduction

Wi‑Fi data rate represents the theoretical PHY layer throughput achievable between a transmitter and receiver.

PHY data rate depends on:
- Modulation scheme
- Coding rate
- Channel width
- Number of spatial streams
- Guard Interval
- OFDM parameters

---

## General Data Rate Formula

Basic formula:

Data Rate = (Bits per Symbol × Coding Rate × Number of Subcarriers × Spatial Streams) / Symbol Duration

---

## Key Parameters

### 1. Modulation Order

Determines:
- Bits carried per symbol

| Modulation | Bits per Symbol |
|---|---|
| BPSK | 1 |
| QPSK | 2 |
| 16‑QAM | 4 |
| 64‑QAM | 6 |
| 256‑QAM | 8 |
| 1024‑QAM | 10 |

---

## 2. Coding Rate

FEC coding improves reliability.

Common coding rates:
- 1/2
- 2/3
- 3/4
- 5/6

Effective payload bits:
Payload Bits = Raw Bits × Coding Rate

---

## 3. Number of Data Subcarriers

OFDM channels contain:
- Data subcarriers
- Pilot subcarriers
- Null carriers

Example:
- 20 MHz OFDM → 52 data subcarriers

---

## 4. Symbol Duration

OFDM symbol duration includes:
- Useful symbol time
- Guard interval

Example:
- 3.2 µs + 0.8 µs = 4 µs

---

## 5. Spatial Streams

MIMO increases throughput by:
- Parallel data streams

Example:
- 2 spatial streams → double throughput

---

## Example Calculation

Example:
- 64‑QAM
- Coding rate = 3/4
- 52 subcarriers
- 1 spatial stream
- Symbol duration = 4 µs

Step 1:
Bits per OFDM symbol:
6 × 52 = 312 bits

Step 2:
Apply coding:
312 × 3/4 = 234 bits

Step 3:
Divide by symbol duration:
234 / 4 µs = 58.5 Mbps

Final PHY Rate:
- 58.5 Mbps

---

## Impact of Channel Width

Wider channels:
- More subcarriers
- Higher throughput

| Channel Width | Approximate Throughput Gain |
|---|---|
| 20 MHz | Baseline |
| 40 MHz | 2× |
| 80 MHz | 4× |
| 160 MHz | 8× |

---

## Impact of Guard Interval

Short Guard Interval:
- Reduces symbol duration
- Increases PHY rate

Example:
- 4 µs → 3.6 µs

Throughput increase:
- Approximately 10%

---

## MCS Index

Wi‑Fi standards use:
- Modulation and Coding Scheme (MCS) index

MCS defines:
- Modulation
- Coding rate
- Spatial stream configuration

---

## Wi‑Fi 6 and Wi‑Fi 7 Improvements

Advanced features:
- OFDMA
- 1024‑QAM
- 4096‑QAM
- Wider channels
- Multi‑Link Operation

Result:
- Multi‑gigabit PHY rates

---

## Theoretical vs Real Throughput

Actual throughput is lower due to:
- MAC overhead
- Retransmissions
- Interference
- Contention
- TCP/IP overhead

Example:
- 1200 Mbps PHY rate
- Real throughput ≈ 700–900 Mbps

---

## Enterprise WLAN Considerations

Engineers analyze:
- MCS distribution
- SNR levels
- Airtime utilization
- Spatial stream usage

Optimization improves:
- Network capacity
- User experience
- Roaming performance

---

## Conclusion

Wi‑Fi data rate calculation depends on multiple PHY layer parameters including modulation, coding rate, OFDM structure, channel width, guard interval, and MIMO spatial streams. Modern Wi‑Fi standards achieve extremely high data rates through advanced modulation schemes, OFDMA, and multi‑antenna technologies. However, actual throughput depends heavily on real‑world RF conditions and protocol overhead.
