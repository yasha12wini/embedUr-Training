# Question 8
## What is the difference between OFDM and OFDMA?

# Answer

OFDM and OFDMA are related PHY technologies used in Wi‑Fi systems, but they differ significantly in how users access subcarriers.

---

# OFDM

OFDM divides a channel into multiple orthogonal subcarriers.

However, during one transmission interval:
- All subcarriers belong to a single user.

This is efficient for high‑speed single‑user transmission.

---

# OFDMA

OFDMA extends OFDM by dividing subcarriers among multiple users simultaneously.

Different users are assigned different Resource Units (RUs).

---

# OFDM vs OFDMA

| Feature | OFDM | OFDMA |
|---|---|---|
| User Access | Single user at a time | Multiple users simultaneously |
| Subcarrier Allocation | Entire channel | Partial channel |
| Efficiency | Good | Excellent in dense networks |
| Latency | Higher contention | Lower latency |
| Wi‑Fi Usage | Wi‑Fi 4/5 | Wi‑Fi 6/7 |
| Scheduling | Simple | Advanced AP scheduling |

---

# OFDMA Resource Units

Wi‑Fi 6 divides channels into:
- 26‑tone RU
- 52‑tone RU
- 106‑tone RU
- 242‑tone RU
- Larger RU groups

This improves:
- IoT communication
- Low latency
- Multi‑user efficiency

---

# Advantages of OFDMA

- Reduced contention
- Lower latency
- Better QoS
- Improved efficiency in crowded environments
- Better uplink/downlink scheduling

---

# Conclusion

OFDMA is an evolution of OFDM optimized for multi‑user environments. It is one of the key technologies enabling the high efficiency of Wi‑Fi 6 and Wi‑Fi 7 networks.
