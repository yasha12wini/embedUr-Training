# Question 12
## How is the data rate calculated?

# Answer

Wi‑Fi data rate depends on several PHY layer parameters such as:
- Channel bandwidth
- Modulation scheme
- Coding rate
- Number of spatial streams
- Guard interval

---

# General Data Rate Formula

The PHY data rate is:

Data Rate = (Bits per Symbol × Coding Rate × Number of Subcarriers × Spatial Streams) / Symbol Duration

---

# Key Parameters

| Parameter | Description |
|---|---|
| Modulation | Determines bits per symbol |
| Coding Rate | Error correction efficiency |
| Spatial Streams | Parallel MIMO streams |
| Channel Width | Available bandwidth |
| Guard Interval | Symbol protection duration |

---

# Bits per Symbol

| Modulation | Bits/Symbol |
|---|---|
| BPSK | 1 |
| QPSK | 2 |
| 16‑QAM | 4 |
| 64‑QAM | 6 |
| 256‑QAM | 8 |
| 1024‑QAM | 10 |

---

# Example Calculation

Assume:
- 64‑QAM
- Coding rate = 3/4
- 52 data subcarriers
- 1 spatial stream
- Symbol duration = 4 µs

Then:

Bits per OFDM symbol:
6 × 3/4 × 52 = 234 bits

Data rate:
234 / 4 µs = 58.5 Mbps

---

# Factors Increasing Data Rate

## 1. Higher Modulation
Higher order QAM increases bits per symbol.

## 2. Wider Channels
40 MHz, 80 MHz, and 160 MHz provide more subcarriers.

## 3. Multiple Spatial Streams
MIMO increases parallel data transmission.

## 4. Short Guard Interval
Reduces overhead.

# Conclusion

Wi‑Fi data rate calculation depends on PHY layer configuration and transmission parameters. Modern standards achieve extremely high throughput using advanced modulation, wider channels, MIMO, and OFDMA technologies.
