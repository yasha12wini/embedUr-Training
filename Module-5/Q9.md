# Fast BSS Transition (802.11r) and Its Benefits in Mobile Environments

## Introduction

802.11r, also called Fast BSS Transition (FT), is a Wi-Fi roaming enhancement standard designed to reduce roaming delay between Access Points (APs).

It is particularly important for:
- Voice-over-Wi-Fi
- Video calls
- Mobile enterprise applications

---

# Problem Before 802.11r

Traditional roaming requires:
- Reauthentication
- Key negotiation
- Full security handshake

This causes delays during AP transitions.

Consequences:
- Voice interruption
- Packet loss
- Application disruption

---

# What is 802.11r?

802.11r optimizes the roaming process by:
- Allowing security keys to be prepared in advance

This reduces authentication overhead during roaming.

---

# Fast Transition Concept

The client establishes:
- Mobility-related security context beforehand

When roaming:
- Full reauthentication is avoided

Result:
- Faster AP transitions

---

# Key Components

## PMK-R0
Root mobility key.

## PMK-R1
Derived per target AP.

These keys enable fast roaming.

---

# Two Modes of Operation

## Over-the-Air FT
Client communicates directly with target AP.

## Over-the-DS FT
Current AP coordinates with target AP via distribution system.

---

# Benefits of 802.11r

## 1. Reduced Roaming Latency

Roaming delay decreases significantly.

Important for:
- Voice calls
- Real-time applications

---

## 2. Improved User Experience

Users experience:
- Fewer interruptions
- Seamless mobility

---

## 3. Better Support for Mobility

Useful in:
- Warehouses
- Hospitals
- Enterprise campuses

where users move frequently.

---

## 4. Reduced Authentication Overhead

Partial security context reuse improves efficiency.

---

# Real-World Example

A user on a VoIP call walks across an office.

Without 802.11r:
- Call may stutter during AP transition

With 802.11r:
- Roaming occurs much faster
- Call continuity improves

---

# Relationship with 802.11k and 802.11v

802.11r focuses on:
- Fast authentication and key transition

While:
- 802.11k improves neighbor discovery
- 802.11v improves roaming decisions

Together they create seamless mobility.

---

# Enterprise Importance

802.11r is critical for:
- Real-time voice
- Mobile healthcare devices
- Industrial mobility
- Enterprise roaming

---

# Key Takeaways

- 802.11r enables fast secure roaming between APs.
- It reduces authentication delay during transitions.
- It greatly improves mobility performance in enterprise WLANs.
