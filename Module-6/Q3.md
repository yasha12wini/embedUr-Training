# Differences Between WEP, WPA, WPA2, and WPA3

## Introduction

WEP, WPA, WPA2, and WPA3 are generations of Wi-Fi security protocols developed to protect wireless communication. Each new generation was introduced to fix weaknesses found in previous protocols.

---

# 1. WEP (Wired Equivalent Privacy)

## Introduction

WEP was the first Wi-Fi security protocol introduced with IEEE 802.11.

## Features
- Uses RC4 encryption
- Static shared keys
- 24-bit Initialization Vector (IV)

## Problems
- Weak encryption
- Small IV causes reuse
- Vulnerable to key recovery attacks
- Easily crackable

## Security Status
Completely insecure and obsolete.

---

# 2. WPA (Wi-Fi Protected Access)

## Introduction

WPA was introduced as a temporary replacement for WEP.

## Features
- Uses TKIP (Temporal Key Integrity Protocol)
- Dynamic key mixing
- MIC integrity protection

## Improvements Over WEP
- Per-packet keying
- Replay protection
- Better integrity checks

## Limitations
- Still based on RC4
- TKIP eventually became insecure

---

# 3. WPA2

## Introduction

WPA2 became the mandatory Wi-Fi security standard based on IEEE 802.11i.

## Features
- AES-CCMP encryption
- Strong confidentiality and integrity
- Supports Personal and Enterprise modes

## Advantages
- Much stronger security
- Resistant to WEP/WPA attacks
- Enterprise-ready

## Limitations
- Vulnerable to weak passwords
- KRACK attack exposed handshake weaknesses

---

# 4. WPA3

## Introduction

WPA3 is the latest Wi-Fi security generation.

## Features
- SAE (Simultaneous Authentication of Equals)
- Forward secrecy
- Stronger cryptography
- Protected management frames mandatory

## Improvements
- Better protection against brute-force attacks
- Stronger public Wi-Fi protection
- Improved IoT onboarding

## Security Benefits
Even if a password is compromised later, older captured sessions remain protected.

---

# Comparison Table

| Feature | WEP | WPA | WPA2 | WPA3 |
|---|---|---|---|---|
| Encryption | RC4 | TKIP/RC4 | AES-CCMP | AES-GCMP |
| Security Level | Very Weak | Weak | Strong | Very Strong |
| Key Handling | Static | Dynamic | Dynamic | Dynamic |
| Authentication | Shared Key | PSK/802.1X | PSK/802.1X | SAE/802.1X |
| Integrity Protection | Weak CRC | MIC | CCMP | Advanced |
| Forward Secrecy | No | No | No | Yes |
| PMF Support | No | Optional | Optional | Mandatory |

---

# Evolution Overview

## WEP → WPA
WPA fixed major WEP weaknesses.

## WPA → WPA2
WPA2 introduced AES-based security.

## WPA2 → WPA3
WPA3 strengthened authentication and password protection.

---

# Enterprise Perspective

Modern enterprise deployments typically use:
- WPA2-Enterprise
- WPA3-Enterprise

with:
- 802.1X
- RADIUS authentication
- Dynamic session keys

---

# Why WPA3 Matters

WPA3 addresses modern threats such as:
- Offline dictionary attacks
- Public hotspot attacks
- Password guessing
- Session compromise

---

# Key Takeaways

- WEP is obsolete and insecure.
- WPA improved WEP but is outdated.
- WPA2 became the industry standard.
- WPA3 provides the strongest Wi-Fi security currently available.
