# EAPOL 4-Way Handshake and Key Derivation Process

## Introduction

The EAPOL 4-way handshake is a critical security mechanism used in WPA/WPA2/WPA3 networks.

Its main objectives are:
- Verify both client and AP possess the same PMK
- Derive encryption keys
- Establish secure communication

The handshake occurs after:
- Authentication
- Association

---

# Key Components

| Key | Purpose |
|---|---|
| PMK | Master key |
| PTK | Pairwise session key |
| GTK | Group encryption key |
| MIC | Integrity protection |

---

# PMK (Pairwise Master Key)

The PMK is:
- Derived from PSK in Personal mode
- Derived from 802.1X/EAP in Enterprise mode

The PMK is never transmitted over the air.

---

# PTK Derivation

PTK is derived using:
- PMK
- ANonce
- SNonce
- MAC addresses

PTK contains:
- Encryption keys
- MIC keys

---

# Step-by-Step 4-Way Handshake

---

# Message 1: AP → Client

AP sends:
- ANonce
- Replay counter

Purpose:
- Begin PTK derivation process

---

# Message 2: Client → AP

Client:
- Generates SNonce
- Derives PTK
- Sends SNonce and MIC

Purpose:
- Prove possession of PMK

---

# Message 3: AP → Client

AP:
- Derives PTK independently
- Verifies MIC
- Sends GTK and MIC

Purpose:
- Confirm AP authentication
- Install encryption keys

---

# Message 4: Client → AP

Client:
- Verifies AP MIC
- Confirms successful key installation

Purpose:
- Finalize handshake

---

# Purpose of Each Key

## PMK
Root secret shared by AP and client.

---

## PTK
Used for:
- Unicast encryption
- Integrity protection

---

## GTK
Used for:
- Broadcast traffic
- Multicast traffic

Shared among clients in same WLAN.

---

# Security Features of the Handshake

## Mutual Authentication
Both sides verify PMK possession.

---

## Fresh Session Keys
New PTKs generated per session.

---

## Replay Protection
Nonces and replay counters prevent replay attacks.

---

## Secure Key Distribution
GTK distributed securely.

---

# What Happens with Wrong Password?

If passphrase is incorrect:
- PMK mismatch occurs
- PTK mismatch occurs
- MIC validation fails
- Handshake terminates

---

# Enterprise Importance

The 4-way handshake is essential for:
- Secure WLAN communication
- WPA2/WPA3 operation
- Enterprise Wi-Fi security

---

# Key Takeaways

- The 4-way handshake derives secure session keys.
- PMK is never transmitted over the air.
- PTK secures unicast traffic.
- GTK secures multicast/broadcast traffic.
- The handshake ensures secure encrypted WLAN communication.
