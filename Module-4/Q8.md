# Medium Access Control Methodologies in Wi-Fi

## Introduction

Wireless communication uses a shared RF medium. Multiple devices attempting to transmit simultaneously can cause collisions and interference.

The MAC layer provides methodologies to coordinate medium access efficiently.

IEEE 802.11 primarily uses:
- CSMA/CA
- Contention-based access
- Optional controlled access mechanisms

---

# Why Medium Access Control is Needed

Unlike wired Ethernet:
- Wireless devices cannot reliably detect collisions while transmitting

Reasons:
- Half-duplex communication
- Signal attenuation
- Hidden node problem

Therefore:
- Collision avoidance is used instead of collision detection.

---

# CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance)

This is the primary MAC methodology in Wi-Fi.

---

# Basic CSMA/CA Operation

## Step 1: Carrier Sensing

The station checks whether:
- Medium is idle
- Channel is busy

---

## Step 2: Interframe Space

If medium becomes idle:
- Station waits for DIFS interval

---

## Step 3: Random Backoff

Station selects:
- Random backoff timer

Timer decrements only when medium is idle.

---

## Step 4: Transmission

When backoff reaches zero:
- Transmission begins

---

## Step 5: ACK Reception

Receiver sends ACK if frame received successfully.

If ACK missing:
- Retransmission occurs

---

# Types of Carrier Sensing

## Physical Carrier Sensing
PHY layer checks RF energy.

## Virtual Carrier Sensing
Uses NAV (Network Allocation Vector).

---

# NAV (Network Allocation Vector)

Frames include duration field.

Other stations:
- Reserve medium virtually
- Avoid transmission

---

# RTS/CTS Mechanism

Used to reduce:
- Hidden node collisions

---

# RTS/CTS Flow

1. Sender sends RTS
2. Receiver replies CTS
3. Data transmission occurs
4. ACK received

---

# Hidden Node Problem

Occurs when:
- Two clients cannot hear each other
- Both transmit simultaneously to AP

RTS/CTS helps mitigate this issue.

---

# Contention-Free Access

Optional mechanism using:
- Point Coordination Function (PCF)

Rarely used in practice.

---

# QoS-Based Access (EDCA)

802.11e introduced:
- Enhanced Distributed Channel Access

Traffic categories receive different priorities.

Examples:
- Voice
- Video
- Best effort

---

# Comparison with Ethernet

| Feature | Ethernet | Wi-Fi |
|---|---|---|
| Access Method | CSMA/CD | CSMA/CA |
| Collision Handling | Detect | Avoid |
| Duplex | Full duplex | Half duplex |

---

# Enterprise Importance

Medium access efficiency directly affects:
- Throughput
- Latency
- Airtime utilization

Dense WLAN optimization heavily depends on MAC access behavior.

---

# Key Takeaways

- Wi-Fi uses CSMA/CA for medium access control.
- Collision avoidance is necessary in wireless communication.
- RTS/CTS helps reduce hidden node problems.
- QoS prioritization improves application performance.
