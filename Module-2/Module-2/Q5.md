# Question 5
## How is the CAPWAP tunnel maintained between AP and controller?

# Answer

CAPWAP tunnels are maintained using keepalive mechanisms, heartbeat messages, DTLS sessions, and periodic control communication between the AP and WLC.

---

# Tunnel Maintenance Process

## 1. Periodic Keepalive Messages
The AP and WLC exchange heartbeat packets regularly.

Purpose:
- Verify tunnel health
- Detect failures
- Maintain session state

---

## 2. DTLS Session Maintenance
If DTLS is enabled:
- Encryption keys are maintained
- Secure sessions remain active
- Reauthentication may occur periodically

---

## 3. Echo Requests and Responses
CAPWAP uses echo messages to confirm:
- Reachability
- Connectivity
- Tunnel integrity

---

# Failure Detection

If keepalive messages fail:
1. AP assumes WLC failure.
2. Tunnel is terminated.
3. AP enters recovery state.
4. AP attempts rediscovery.

---

# AP Recovery Behavior

Depending on configuration:
- AP may continue serving clients
- AP may enter standalone mode
- AP may search for backup WLC

---

# High Availability Support

Enterprise deployments use:
- Primary WLC
- Secondary WLC
- Mobility groups
- Fast failover mechanisms

---

# Conclusion

CAPWAP tunnel maintenance ensures continuous AP‑controller communication using periodic health checks, secure session management, and automatic recovery mechanisms.
