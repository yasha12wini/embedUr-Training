# Question 7
## If WLC is deployed in WAN, which AP mode is best for local network and how?

# Answer

When the Wireless LAN Controller (WLC) is deployed across a WAN, FlexConnect mode is the best AP operating mode for local branch networks.

---

# What is FlexConnect Mode?

FlexConnect allows lightweight APs to:
- Continue centralized management through WLC
- Locally switch client traffic at branch sites

---

# Why FlexConnect is Best for WAN Deployments

## 1. Local Traffic Switching
Client traffic does not need to traverse WAN links.

Benefits:
- Reduced WAN bandwidth usage
- Lower latency
- Faster local access

---

## 2. WAN Failure Resilience
If WAN connectivity to WLC fails:
- AP can continue serving clients locally
- Authentication may continue using cached credentials

---

## 3. Centralized Management
Even though traffic switches locally:
- Configuration remains centralized
- Policies remain centrally managed

---

# FlexConnect Operation

```text
Wireless Client
       |
       v
   FlexConnect AP
       |
Local Switching
       |
       v
   Local LAN

Control Traffic --> WLC over WAN
```

---

# Advantages

| Advantage | Benefit |
|---|---|
| Reduced WAN Usage | Saves bandwidth |
| Better Performance | Lower latency |
| WAN Failure Support | Local survivability |
| Centralized Control | Easier management |

---

# Conclusion

FlexConnect is ideal for distributed branch deployments because it combines centralized WLAN management with local traffic forwarding and WAN survivability.
