# Question 6
## What is the difference between Sniffer mode and Monitor mode? Use cases for each mode.

# Answer

Sniffer mode and Monitor mode are special AP operating modes used for WLAN troubleshooting, packet analysis, and security monitoring.

---

# Monitor Mode

In Monitor mode:
- AP scans wireless channels.
- AP does not serve clients.
- AP analyzes RF activity.

---

# Monitor Mode Functions

- Rogue AP detection
- Interference analysis
- Intrusion detection
- RF scanning
- Spectrum monitoring

---

# Sniffer Mode

In Sniffer mode:
- AP captures wireless packets.
- Packets are forwarded to a packet analyzer.

Example:
- Wireshark analysis

---

# Sniffer Mode Functions

- Packet capture
- WLAN troubleshooting
- Frame analysis
- Debugging authentication issues

---

# Comparison Table

| Feature | Monitor Mode | Sniffer Mode |
|---|---|---|
| Main Purpose | RF monitoring | Packet capture |
| Client Service | No | No |
| Packet Storage | No | Yes |
| Security Analysis | Yes | Limited |
| Troubleshooting | Moderate | Excellent |
| Tool Integration | WLC dashboards | Wireshark |

---

# Use Cases

## Monitor Mode
- Detect rogue APs
- Analyze interference
- Wireless intrusion prevention

## Sniffer Mode
- Debug authentication failures
- Capture 802.11 frames
- Analyze roaming problems

---

# Conclusion

Monitor mode focuses on wireless security and RF analysis, while sniffer mode is designed for detailed packet capture and protocol troubleshooting.
